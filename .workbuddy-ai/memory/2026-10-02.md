## 踩到的坑（都已在文档里记录）

### 1. `uv sync` 不装 workspace 成员

`uv sync` 默认只装根项目依赖，6 个成员包一个都不装。
必须 `uv sync --all-packages`。已写进 README 与 setup.md。

### 2. 内存 SQLite 的多连接隔离

测试用 `sqlite:///:memory:` 会导致随机的 `no such table` ——
SQLite 的内存库是「每连接一个独立数据库」，连接池换连接就看不到表。
改用临时文件数据库。

### 3. 代理环境变量劫持 127.0.0.1

开发机上的 `http_proxy` 会把发往 mock 站点的请求也转出去，
症状是「mock 站点连不上」，看起来像服务没起。conftest 里统一清除。

### 4. YAML 双引号里的 `\S` 是非法转义

`regex: "作者：(\S+)"` 会直接让 YAML 解析失败。正则必须用单引号。

### 5. XPath 的 `@class="x"` 是精确匹配

节点上还有别的类名（`class="book-item odd"`）就匹配不上，要写 `contains(@class,'x')`。

## 修掉的真实代码 bug（写测试时暴露的）

| Bug | 后果 | 修法 |
|---|---|---|
| `Rule.is_empty` 按选择器判空 | `chapterName: "text"` 这类「作用于元素自身」的规则被丢弃，**Legado 目录永远是空的** | 改为按原始规则串判空 |
| 原生书源工厂从未注册 | 原生书源完全无法创建适配器 | 新增 `register_native()` |
| `allow_private_network` 开关没接上 | 全局安全开关形同虚设 | 引入 `HttpFactory` 由注册表注入 |
| 原生书源 ID 随机生成 | 重复导入不幂等 | 改用 `stable_id()` 按地址派生 |
| 原生书源正文先转纯文本再清洗 | `<script>` 内容混进正文 | 改为把 HTML 交给 normalizer |
| `content` 规则忽略配置的 url | 请求到了详情页而非正文页 | 新增 `_resolve()` 统一地址解析 |
| `build_native_source` 的 origin 是 keyword-only | 按位置调用直接 TypeError | 改为位置参数 |
| `auth.py` 的 bytes 字面量含中文 | 语法错误，服务起不来 | 改 `json.dumps().encode()` |
